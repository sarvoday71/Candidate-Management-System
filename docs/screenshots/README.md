# Screenshots

The images in this folder are shown in the main [README](../../README.md#screenshots).
Save each screenshot with **exactly** the filename below and the README picks it up with no edits.

| File | What to capture | Suggested size |
|---|---|---|
| `dashboard.png` | Main page: the four stat cards, status chips and the candidate table with several rows | 1440 x 900 |
| `filters.png` | "More filters" panel open with a few filters applied (for example a skill, a location, a minimum experience) and the results narrowed | 1440 x 900 |
| `add-candidate.png` | The "Add candidate" modal with the form filled in, including a couple of skill tags | 1440 x 900 |
| `validation-error.png` | The modal showing validation errors (empty required fields), or the duplicate-email error | 1440 x 900 |
| `delete-confirm.png` | The "Delete candidate?" confirmation dialog | 1440 x 900 |

## Tips

- Use **PNG**. On Windows, `Win + Shift + S` captures a region.
- Add 8-10 realistic **fake** candidates first so the table and stats look populated. Don't use real people's names, emails or phone numbers.
- Make sure the browser's address bar, bookmarks and other tabs aren't in the shot, and that no connection strings or passwords are visible anywhere.
- Keep each file reasonably small (under ~500 KB) so the repository stays light.
